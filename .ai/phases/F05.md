# F05 — Screen Composer con Puck

Estado de fase: `IN_PROGRESS`.

## Objetivo
Integrar Puck como único Screen Composer del Studio sin persistir internals del engine ni duplicar su editor.

## Microfase activa

`M05.1 — Crear PuckAdapter y component mapping`.

## Reglas
- Puck se consume detrás de `@electrocraft/editor-puck`.
- `ElectroCraftDocument` es el modelo portable; AppState/history/zones no se persisten.
- Usar Composition/Slots/Fields/Outline/Preview públicos de Puck.
- Diagnostics unknown/unsupported permanecen visibles y reparables.
- Editor history y Project Revisions son historias separadas.
- Base CI es el gate transversal por defecto.
