# M12.3 — Refine AccessControl adapter

**Fase propietaria:** F12 — Usuarios, autenticación y permisos

## Por qué existe
Esta microfase existe para **Refine AccessControl adapter** dentro de la responsabilidad de `F12`: resolver auth/permissions/audit. Debe cerrar una capacidad concreta y no abrir un subsystem paralelo.

## Resultado exacto
Al cerrar esta microfase, **Refine AccessControl adapter** debe existir como capacidad real, integrada y verificable. No se acepta placeholder ni una implementación paralela al engine.

## Engine owner
`Refine Access/Auth/Audit`

### Regla
Antes de escribir código, consulta la API pública del engine. Si ya existe la capacidad, úsala. ElectroCraft solo debe aportar canonical mapping, configuración, UX, adapter, target semantics o exportación.

## Implementación línea por línea
1. Wrap evaluator as accessControlProvider.
2. Use CanAccess/useCan where appropriate.
3. Menus/buttons react to same evaluator.
4. Protected routes also enforced.
5. No duplicate RBAC logic.
6. Actualiza Auth/Policy contracts.
7. Implementa provider/evaluator/use-cases.
8. Conecta route/resource/field/action enforcement.
9. Construye Users/Roles/Simulator UI.
10. Añade deny-path tests además de allow-path.
