# M00.9 — POC Data Sources: REST/OpenAPI, GraphQL y Gateway

**Fase propietaria:** F00 — Auditoría de producto, OSS y POCs

## Por qué existe
Fuentes de datos es una nueva capacidad central de ElectroCraft. Antes de congelar F08 hay que demostrar que el contrato puede manejar internal/REST/GraphQL y separar credenciales mediante Gateway sin inventar un backend universal.

## Resultado exacto
POC ejecutable que demuestra una misma `DataSourceAdapter` contract para una REST operation y una GraphQL operation, más un Gateway fake/server adapter para un secreto que nunca llega al cliente.

## Engine owner
`Web Fetch API + OpenAPI parser OSS aprobado + GraphQL protocol + ElectroCraft DataSourceAdapter`

## Responsabilidad ElectroCraft
Definir semántica portable de source/operation/capabilities/SecretRef y normalizar resultados; no construir un HTTP stack ni GraphQL engine propios.

## Implementación paso por paso
1. Define POC interface `DataSourceAdapter` con capabilities, listResources/getSchema y execute operation.
2. Implementa REST adapter con una fixture OpenAPI pequeña y una operación GET/POST mock/local.
3. Evalúa 1–2 parsers OpenAPI OSS actuales por licencia, mantenimiento, bundle y capacidad de resolver schemas/operations; documenta decisión.
4. Implementa GraphQL adapter contra schema/mock endpoint local, con query y mutation variables.
5. Normaliza ambos a `DataResult {data, errors, pageInfo, meta}`.
6. Implementa SecretRef y un Gateway mock/server endpoint; demuestra que el client payload contiene ref pero no valor.
7. Simula CORS/direct-safe vs gateway-required policy.
8. Prueba unsupported mutation capability y error normalization.
9. Mide dependencia/bundle básico para confirmar que Core no necesita drivers SQL server.
10. Escribe ADR con la decisión de connectors Core y optional connector packs.
11. Aísla el experimento; no importes implementación de producto no aprobada.
12. Define fixture mínimo reproducible.
13. Ejecuta la API OSS real que se está evaluando.
14. Mide el gap entre OSS y semántica ElectroCraft.
15. Documenta decisión/limitación/licencia/API usada.
16. Guarda logs/artifacts en evidence.
