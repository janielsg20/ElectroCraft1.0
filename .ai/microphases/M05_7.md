# M05.7 — Extensiones de palette y outline solo necesarias

**Fase propietaria:** F05 — Screen Composer con Puck

## Por qué existe
Esta microfase existe para **Extensiones de palette y outline solo necesarias** dentro de la responsabilidad de `F05`: integrar Puck sin duplicar su editor. Debe cerrar una capacidad concreta y no abrir un subsystem paralelo.

## Resultado exacto
Al cerrar esta microfase, **Extensiones de palette y outline solo necesarias** debe existir como capacidad real, integrada y verificable. No se acepta placeholder ni una implementación paralela al engine.

## Engine owner
`Puck`

### Regla
Antes de escribir código, consulta la API pública del engine. Si ya existe la capacidad, úsala. ElectroCraft solo debe aportar canonical mapping, configuración, UX, adapter, target semantics o exportación.

## Packages/área de código

## Precondiciones
- `M05.6` COMPLETADA.
- Engine owner disponible detrás de su adapter.
- No existen errores P0/P1 de la dependencia inmediata.
- Tests existentes están verdes antes de modificar comportamiento.

## Implementación línea por línea
1. Añade search/category/favorites/recent como capas de descubrimiento alrededor del catálogo, sin sustituir `Puck.Components`.
2. `favorites` y `recent` son Workspace/User preferences, no ComponentDefinitions duplicadas.
3. Para rename/lock/visibility de Outline, usa primero APIs/permissions/composition públicas de Puck.
4. `lock` mapea permissions de edit/drag/delete/duplicate cuando aplique; `hidden` permanece propiedad/condition Electro.
5. No uses `overrides` o plugins experimentales como única forma de conservar una función release-critical.
6. Si una extensión avanzada exige API inestable, documenta adapter + fallback y revalida en dependency pinning.
7. Puck AI permanece fuera del core por dependencia cloud; solo puede existir como future optional provider.
8. Prueba que deshabilitar extensiones Electro deja Puck base funcional.
9. Actualiza mapping ElectroCraftDocument <-> Puck projection.
10. Usa Puck public Composition/Slots/Fields/Outline/Preview en vez de recrearlos.
11. Conecta changes a canonical commands/repository.
12. Mantén history de editor separado de revisions.
13. Prueba round-trip/nesting/selection/history.
