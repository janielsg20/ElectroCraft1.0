# M07.8 — Navigation E2E y UX

**Fase propietaria:** F07 — Pantallas, navegación y rutas

## Por qué existe
La fase termina solo si las pantallas, rutas y navigation model funcionan como una sola experiencia.

## Resultado exacto
Al cerrar esta microfase, **Navigation E2E y UX** existe como capacidad real, conectada a los contratos de ElectroCraft y demostrada con pruebas. No se acepta placeholder, botón decorativo ni contrato sin consumidor.

## Engine owner
`All navigation contracts + AppShell`

## Responsabilidad ElectroCraft
ElectroCraft conserva únicamente la semántica portable, la UX española, los adapters, permisos, validación, persistencia y compatibilidad multi-target. El engine OSS conserva la responsabilidad técnica para la que fue elegido.

## Ubicación de código obligatoria
- `packages/domain/src/navigation/`
- `packages/application/src/navigation/`
- `apps/studio/src/features/navigation/`

## Ubicación exacta en la app
`Pantallas`, `App > Navegación`, `Editor` y Preview stub.

## Diseño visual exacto
Audita Desktop/Tablet/Mobile, español, ayuda y keyboard.

## Texto visible en español
Pantallas; Navegación; Ruta; Abrir en Editor; Pantalla inicial.

## Ayuda contextual
Usa HelpRegistry `help.navigation`. El título de pantalla lleva `CircleHelp`; los conceptos técnicos usan `Info` solo cuando aportan contexto real.

## Precondiciones
- Gate de entrada de la fase satisfecho.
- Contratos/engines anteriores verdes.
- No existe una implementación paralela de la misma responsabilidad.

## Implementación paso por paso
1. E2E create 4 screens.
2. Build Stack containing Tabs and modal.
3. Assign routes/params.
4. Open each screen in Editor.
5. Configure navigation action with param.
6. Run contract preview/stub navigation.
7. Test delete referenced screen blocker.
8. Audit Spanish/help/responsive/accessibility.
9. Actualiza Navigation/Route contracts primero.
10. Implementa use-case/ref integrity.
11. Construye tree editor español.
12. Añade target compiler contract fixture sin persistir router objects.
13. Prueba params/deep-links/guards/ref rename.

## Artefactos obligatorios al cerrar
- `Navigation E2E report`
- `screenshots/evidence`

## Estados UI obligatorios
- Inicial.
- Cargando, solo cuando haya espera perceptible.
- Vacío con explicación y CTA.
- Error en español con recuperación.
- Deshabilitado con motivo.
- Guardando/Aplicando cuando corresponda.
- Éxito breve y accionable.

## Responsive
- Desktop: alta densidad sin comprimir la tarea principal.
- Tablet: panel secundario a Sheet/Drawer.
- Mobile: flujo por rutas/pasos; no reducir una UI desktop de tres columnas.

## Accesibilidad
- teclado;
- focus-visible;
- labels persistentes;
- icon-only con aria-label;
- errores anunciables;
- touch targets;
- reduced motion;
- alternativa a drag cuando aplique.
