# M25.1 — Descriptor LAMP y configuración del target

**Fase propietaria:** F25 — Exportación LAMP con Slim/PDO

## Por qué existe
LAMP vuelve a ser Core y necesita exactamente el mismo TargetDescriptor/Export Center/Capability contract que Web, Native y WordPress.

## Resultado exacto
Al cerrar esta microfase, **Descriptor LAMP y configuración del target** funciona de forma observable dentro del target correspondiente y pasa su gate. No se acepta un archivo generado sin validación ni una opción visual sin compiler/runtime real.

## Engine owner
`Slim/PHP target metadata + ExportTargetRegistry`

## Responsabilidad ElectroCraft
ElectroCraft implementa únicamente el mapping desde modelos canónicos, la UX española, configuración, validación, diagnósticos, seguridad, compilación y evidencia. El framework/SDK target conserva routing/runtime/API behavior que ya ofrece.

## Ubicación de código obligatoria
- `packages/export-lamp/`
- `packages/export-core/`

## Ubicación exacta en la app
`Publicar > Exportar > LAMP`.

## Diseño visual exacto
Export Center estándar. Config: Servidor, PHP, Base de datos, Assets, Dependencias, Seguridad, Instalación. Compatibilidad siempre visible a la derecha.

## Texto visible en español
LAMP; PHP; MySQL/MariaDB; Servidor; Dependencias; Instalación; Analizar; Generar.

## Ayuda contextual
Usa HelpRegistry `help.export.lamp`. El H1 usa `CircleHelp`; las opciones técnicas muestran Info solo cuando explican una decisión o requisito del target.

## Precondiciones
- Gate de la fase anterior satisfecho.
- ExportIR/TargetRegistry/Capability Analyzer disponibles.
- Tests existentes verdes antes de modificar el target.
- No existe un exporter paralelo para la misma responsabilidad.

## Implementación paso por paso
1. Registra `lamp` como Core target.
2. Define config: public path, base URL, DB driver mysql, env names, includeVendor, pretty URLs, session/cookie settings.
3. No fija PHP version por memoria; F00/release verifica baseline soportado.
4. Define artifact kinds: source package y deployable zip.
5. Define toolchain verifier: PHP, Composer, MySQL/MariaDB fixture.
6. Añade HelpDescriptor y Export Center UI.
7. Contract-test target parity.
8. Compila Routes a Slim, Data a PDO/MySQL y Screens a HTML/PHP.
9. Usa Slim/PSR-7/CSRF/PDO; no infra HTTP/DB propietaria.
10. Genera Composer/migrations/env example.
11. Ejecuta clean install + HTTP/security tests.
12. Empaqueta ZIP y verifica checksum.
