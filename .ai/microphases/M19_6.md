# M19.6 — Integrar Permission Simulator existente en Preview

**Fase propietaria:** F19 — Vista previa, Debug y runtime diagnostics

## Por qué existe
Esta microfase existe para **Integrar Permission Simulator existente en Preview** dentro de la responsabilidad de `F19`: previsualizar/diagnosticar runtime. Debe cerrar una capacidad concreta y no abrir un subsystem paralelo.

## Resultado exacto
Al cerrar esta microfase, el **Permission Simulator construido en F12** debe estar integrado en Preview sin crear una segunda implementación. No se acepta placeholder ni una implementación paralela al engine.

`runtime-web/Refine runtime`

Antes de escribir código, consulta la API pública del engine. Si ya existe la capacidad, úsala. ElectroCraft solo debe aportar canonical mapping, configuración, UX, adapter, target semantics o exportación.

## Implementación línea por línea
1. Importa/consume el Permission Simulator público construido en F12; no copies su evaluator, state model ni UI base.
2. Añade al toolbar/debug context de Preview un control `Simular rol` que abre el selector existente.
3. Cuando el usuario selecciona un rol, crea un simulation context efímero y pásalo al Preview Permission Context.
4. Muestra un banner persistente `Simulación: <rol>` mientras el Preview use ese contexto.
5. Añade acción `Salir de simulación` que restaura el contexto real sin alterar la sesión autenticada.
6. Verifica que rutas, botones, fields y actions del Preview usan el mismo ElectroCraftPermissionEvaluator de F12.
7. No persistas la simulación dentro de ElectroCraftProject ni del usuario real.
8. Prueba que cambiar de documento/ruta mantiene la simulación solo mientras el usuario permanezca en Preview.
9. Define input y output tipados de la integración.
10. Añade E2E antes de marcar el resultado terminado.
11. Ejecuta runtime real, no screenshot/mock.
12. Conecta route/role/platform selectors.
13. Instrumenta traces sin exponer secrets.
14. Aísla effects de Preview cuando sea necesario.
15. Prueba Web/Admin/Native modes y Debug.
