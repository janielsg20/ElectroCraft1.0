# M18.11 — Generar texto, datos de demostración e imágenes con Gemini

**Fase propietaria:** F18 — Generar con IA — Gemini

## Por qué existe
Contenido reutilizable incluye copy, records demo e imágenes. Estos outputs necesitan destinos y controles distintos a los documentos visuales.

## Resultado exacto
Al cerrar esta microfase, **Generar texto, datos de demostración e imágenes con Gemini** está implementada de extremo a extremo para su alcance y produce evidencia real.

## Engine owner
`Gemini text/structured/image generation + Media staging`

## Responsabilidad ElectroCraft
ElectroCraft controla contratos, contexto, UX en español, permisos, validación, borradores, diff y Apply. El proveedor de IA nunca muta el proyecto directamente.

## Ubicación de código obligatoria
- `packages/ai/`
- `apps/studio/src/features/ai/`
- `apps/studio/src/components/ai-elements/`

## Ubicación exacta en la app
`Generar con IA`: Contenido e Imagen. También disponible como acción contextual `Generar con IA` desde un Text/Image/Media field.

## Diseño visual exacto
Content result has destination selector. Image result has aspect ratio/size/reference controls and Media preview.

## Texto y ayuda
Todo texto visible usa i18n español. El título de la sección lleva `CircleHelp`; las opciones técnicas no obvias usan `Info` con HelpRegistry. Nunca mostrar raw provider errors como texto principal.

## Texto visible en español
Generar con IA; Crear; Historial; Contexto; Opciones; Validación; Generar; Aplicar cambios; Guardar como reutilizable.

## Ayuda contextual
Usa HelpRegistry `help.ai`. Si esta microfase introduce un concepto nuevo, añade/actualiza su HelpDescriptor en español. La ayuda crítica no puede vivir solo en un tooltip.

## Implementación paso por paso
1. Text generation returns draft text with destination ref; never writes/publishes directly.
2. Demo records use structured output validated against ElectroCraftDataSchema and are labeled Datos de demostración.
3. Image generation uses current verified Gemini native image model through provider profile=image.
4. Do not use deprecated Imagen architecture as default.
5. Image references/context are sent only when selected by user.
6. Stage image bytes in AI draft media store, not MediaBlobStore final.
7. Show aspect ratio/size options supported by current provider capabilities.
8. On Apply move/copy bytes to MediaBlobStore and create Media metadata with AI origin.
9. Generated textual facts using optional web grounding keep source metadata in draft when provider supplies it.
10. Copyright/source claims are not invented; generated origin is labeled.
11. Define request/draft schema antes de prompt/UI.
12. Usa AI SDK para model/tools/structured output y AI Elements para UI estándar.
13. Todas las tools escriben Draft o leen contexto sanitizado.
14. Valida/Preview/Diff antes de Apply.
15. Aplica solo por AIApplyService transaccional.
16. Prueba mock determinista + security + Spanish.
