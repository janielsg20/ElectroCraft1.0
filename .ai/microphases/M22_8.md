# M22.8 — Expo Router stable Stack/JS Tabs compiler

**Fase propietaria:** F22 — Runtime Native con Expo

## Por qué existe
Esta microfase existe para **Expo Router stable Stack/JS Tabs compiler** dentro de la responsabilidad de `F22`: generar runtime Expo/data/router/admin. Debe cerrar una capacidad concreta y no abrir un subsystem paralelo.

## Resultado exacto
Al cerrar esta microfase, **Expo Router stable Stack/JS Tabs compiler** debe existir como capacidad real, integrada y verificable. No se acepta placeholder ni una implementación paralela al engine.

## Engine owner
`Expo Router + Expo SQLite + Drizzle`

### Regla
Antes de escribir código, consulta la API pública del engine. Si ya existe la capacidad, úsala. ElectroCraft solo debe aportar canonical mapping, configuración, UX, adapter, target semantics o exportación.

## Precondiciones
- `M22.7` COMPLETADA.
- Engine owner disponible detrás de su adapter.

- Tests existentes están verdes antes de modificar comportamiento.

## Implementación línea por línea
1. Compila ElectroRoute a files/layouts Expo Router.
2. Default root/navigation uses stable `Stack`.
3. Use standard JavaScript Tabs only when the route profile requests tabs.
4. Do NOT generate `unstable-native-tabs` by default while the installed Expo Router version marks it alpha/unstable.
5. Generated application code uses Expo Router navigation APIs; avoid direct `@react-navigation/*` imports unless the verified Expo Router adapter explicitly requires them.
6. Generate typed path/param helpers from ElectroRoute IDs.
7. Unknown route -> not-found/404 screen equivalent.
8. Deep-link scheme/config generated from export profile.
9. Permission guard wraps route using ElectroCraftPermission/Auth context.
10. Test direct deep link, protected route, Stack, JS Tabs and not-found.
11. Mapea canonical components/navigation/data/state/actions a RN/Expo adapters.
12. No reutilices DOM components.
13. Implementa Expo Router/SQLite only from portable definitions.
14. Añade accessibility and device-safe behavior.
15. Prueba runtime fixture.
