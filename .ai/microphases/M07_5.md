# M07.5 — Route params, deep links y navegación por acciones

**Fase propietaria:** F07 — Pantallas, navegación y rutas

## Por qué existe
Las pantallas deben recibir datos y poder navegar mediante acciones portables.

## Resultado exacto
Al cerrar esta microfase, **Route params, deep links y navegación por acciones** existe como capacidad real, conectada a los contratos de ElectroCraft y demostrada con pruebas. No se acepta placeholder, botón decorativo ni contrato sin consumidor.

## Engine owner
`Routes + Binding + Action contracts`

## Responsabilidad ElectroCraft
ElectroCraft conserva únicamente la semántica portable, la UX española, los adapters, permisos, validación, persistencia y compatibilidad multi-target. El engine OSS conserva la responsabilidad técnica para la que fue elegido.

## Ubicación de código obligatoria
- `packages/domain/src/navigation/`
- `packages/application/src/navigation/`
- `apps/studio/src/features/navigation/`

## Ubicación exacta en la app
`App > Navegación > Rutas` y `Inspector > Acciones > Navegar`.

## Diseño visual exacto
Route detail con Path/Params/Deep link/Guard. Action editor ofrece Destino/Params/Modo push|replace|back.

## Texto visible en español
Parámetros; Enlace profundo; Destino; Reemplazar; Volver; Abrir enlace externo.

## Ayuda contextual
Usa HelpRegistry `help.navigation.routes`. El título de pantalla lleva `CircleHelp`; los conceptos técnicos usan `Info` solo cuando aportan contexto real.

## Precondiciones
- Gate de entrada de la fase satisfecho.
- Contratos/engines anteriores verdes.
- No existe una implementación paralela de la misma responsabilidad.

## Implementación paso por paso
1. Define typed route param schema.
2. Binding source `route param` valida tipo.
3. Navigation action acepta route/screen ref y param mappings.
4. Define external URL action separately.
5. Compilers Web/Native later map semantics.
6. Prueba missing param, type mismatch, deep link and action ref rename.
7. Actualiza Navigation/Route contracts primero.
8. Implementa use-case/ref integrity.
9. Construye tree editor español.
10. Añade target compiler contract fixture sin persistir router objects.
11. Prueba params/deep-links/guards/ref rename.
