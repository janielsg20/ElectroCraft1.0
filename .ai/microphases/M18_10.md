# M18.10 — Generar apps completas, Kits de App y Extensiones/Plugins

**Fase propietaria:** F18 — Generar con IA — Gemini

## Por qué existe
El usuario pidió crear contenido reutilizable de alto nivel, incluyendo plugins. Debe hacerse sobre los packages ya definidos, no con instalación de código automática.

## Resultado exacto
Al cerrar esta microfase, **Generar proyectos completos, Project Kits y Extensiones/Plugins** está implementada de extremo a extremo para su alcance y produce evidencia real.

## Engine owner
`ElectroCraftBlueprint/ProjectKit/ElectroCraftExtensionPackage + Gemini`

## Responsabilidad ElectroCraft
ElectroCraft controla contratos, contexto, UX en español, permisos, validación, borradores, diff y Apply. El proveedor de IA nunca muta el proyecto directamente.

## Ubicación de código obligatoria
- `packages/ai/`
- `apps/studio/src/features/ai/`
- `apps/studio/src/components/ai-elements/`

## Ubicación exacta en la app
`Generar con IA`: Proyecto completo y Extensión / Plugin. El resultado se revisa con un checklist de Impacto, Permisos, Compatibilidad y Código.

## Diseño visual exacto
Header de resultado muestra badge `Declarativa` o `Requiere revisión de código`.

## Texto y ayuda
Todo texto visible usa i18n español. El título de la sección lleva `CircleHelp`; las opciones técnicas no obvias usan `Info` con HelpRegistry. Nunca mostrar raw provider errors como texto principal.

## Texto visible en español
Generar con IA; Crear; Historial; Contexto; Opciones; Validación; Generar; Aplicar cambios; Guardar como reutilizable.

## Ayuda contextual
Usa HelpRegistry `help.ai`. Si esta microfase introduce un concepto nuevo, añade/actualiza su HelpDescriptor en español. La ayuda crítica no puede vivir solo en un tooltip.

## Precondiciones
- F17 COMPLETADA: los tipos de artifact reutilizable y ElectroCraftExtensionPackage existen.
- F00 POC Gemini aprobado.
- i18n/HelpRegistry/AppShell disponibles.
- provider secrets fuera del cliente.

## Implementación paso por paso
1. Proyecto completo genera Blueprint/Project Kit draft usando existing artifact generators.
2. Extension generation defaults to declarative ElectroCraftExtensionPackage.
3. Show package contents grouped: Diseño, Datos, Formularios, Acciones, Administración, Ayuda, Media.
4. Run conflict resolver against current project/library.
5. Run capability/permission review.
6. If model proposes custom code, store source only in quarantined codeModules and mark draft Requires Code Review.
7. Generate package README_ES with purpose/install/permissions/uninstall behavior.
8. Do not install extension from model tool; user Apply/Install is separate.
9. Allow saving package to Extensiones > Borradores without installing it.
10. Define request/draft schema antes de prompt/UI.
11. Usa AI SDK para model/tools/structured output y AI Elements para UI estándar.
12. Todas las tools escriben Draft o leen contexto sanitizado.
13. Valida/Preview/Diff antes de Apply.
14. Aplica solo por AIApplyService transaccional.
15. Prueba mock determinista + security + Spanish.
