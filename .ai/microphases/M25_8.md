# M25.8 — Seguridad, E2E y paridad LAMP

**Fase propietaria:** F25 — Exportación LAMP con Slim/PDO

## Por qué existe
LAMP no tiene estatus igual si no pasa seguridad y el mismo proyecto canónico que los demás exporters.

## Resultado exacto
Al cerrar esta microfase, **Seguridad, E2E y paridad LAMP** funciona de forma observable dentro del target correspondiente y pasa su gate. No se acepta un archivo generado sin validación ni una opción visual sin compiler/runtime real.

## Engine owner
`Slim/PDO security stack + ElectroCraft parity harness`

## Responsabilidad ElectroCraft
ElectroCraft implementa únicamente el mapping desde modelos canónicos, la UX española, configuración, validación, diagnósticos, seguridad, compilación y evidencia. El framework/SDK target conserva routing/runtime/API behavior que ya ofrece.

## Ubicación de código obligatoria
- `packages/export-lamp/`

- `fixtures/lamp/`

## Ubicación exacta en la app
No UI nueva; valida `Compatibilidad/Exportar > LAMP`.

## Diseño visual exacto
Export report must include routing, data, forms, auth, security and parity evidence.

## Texto visible en español
Paridad LAMP; Seguridad; Pruebas HTTP; Migraciones; Listo.

## Ayuda contextual
Usa HelpRegistry `help.export.parity`. El H1 usa `CircleHelp`; las opciones técnicas muestran Info solo cuando explican una decisión o requisito del target.

## Precondiciones
- Gate de la fase anterior satisfecho.
- ExportIR/TargetRegistry/Capability Analyzer disponibles.
- Tests existentes verdes antes de modificar el target.
- No existe un exporter paralelo para la misma responsabilidad.

## Implementación paso por paso
1. Export canonical fixture to LAMP.
2. Composer install and migrate clean MySQL/MariaDB fixture.
3. Run HTTP E2E for screens/routes/forms/auth/admin.
4. Run CSRF, injection, XSS/escaping, unauthorized, upload negative tests.
5. Verify external source secret stays server-side.
6. Compare expected semantic snapshot with target adaptations.
7. Verify deploy ZIP and checksum.
8. Archive logs and screenshots.
9. Compila Routes a Slim, Data a PDO/MySQL y Screens a HTML/PHP.
10. Usa Slim/PSR-7/CSRF/PDO; no infra HTTP/DB propietaria.
11. Genera Composer/migrations/env example.
12. Ejecuta clean install + HTTP/security tests.
13. Empaqueta ZIP y verifica checksum.
