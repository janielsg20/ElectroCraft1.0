# M08.3 — REST API Connector y OpenAPI import

**Fase propietaria:** F08 — Fuentes de datos, modelos internos, registros y conectores

## Por qué existe
Las apps No-Code deben consumir APIs externas sin escribir fetch manual en cada pantalla.

## Resultado exacto
Al cerrar esta microfase, **REST API Connector y OpenAPI import** existe como capacidad real, conectada a los contratos de ElectroCraft y demostrada con pruebas. No se acepta placeholder, botón decorativo ni contrato sin consumidor.

## Engine owner
`Web Fetch API + DataSourceAdapter; OpenAPI parser elegido en F00`

## Responsabilidad ElectroCraft
ElectroCraft conserva únicamente la semántica portable, la UX española, los adapters, permisos, validación, persistencia y compatibilidad multi-target. El engine OSS conserva la responsabilidad técnica para la que fue elegido.

## Ubicación de código obligatoria
- `packages/connectors/`
- `packages/data-web/`

## Ubicación exacta en la app
`Datos > Fuentes de datos > Nueva fuente > REST API`.

## Diseño visual exacto
Wizard: Endpoint base -> Autenticación -> OpenAPI/Manual -> Operaciones -> Probar -> Guardar. Desktop max 820; mobile full-screen.

## Texto visible en español
REST API; URL base; Autenticación; Importar OpenAPI; Operaciones; Probar solicitud; Guardar fuente.

## Ayuda contextual
Usa HelpRegistry `help.data.rest`. El título de pantalla lleva `CircleHelp`; los conceptos técnicos usan `Info` solo cuando aportan contexto real.

## Precondiciones
- Gate de entrada de la fase satisfecho.
- Contratos/engines anteriores verdes.
- No existe una implementación paralela de la misma responsabilidad.

## Implementación paso por paso
1. Define REST source config: baseUrl, authRef, default headers sans secrets, timeout, operation catalog.
2. Permite importar OpenAPI JSON/YAML con parser OSS aprobado en F00 o configurar operaciones manualmente.
3. Convierte operations a `DataOperationDefinition` con method/path/input/output schema/pagination hints.
4. Usa parameter/path/query/header/body mapping tipado.
5. Ejecuta desde browser solo si CORS/security policy lo permite; de lo contrario usa ConnectorGateway.
6. Normaliza response/error/pagination a ElectroCraftDataResult.
7. Prueba GET/POST, params, auth ref missing, 4xx/5xx, timeout, CORS/gateway mode.
8. Define DataSource/DataModel contract/capabilities.
9. Implementa adapter/repository behind ConnectorRegistry.
10. Resuelve secrets por SecretRef/Gateway.
11. Construye Data UI/Explorer/Model UI indicada.
12. Prueba schema/capabilities/CRUD/error/security.
