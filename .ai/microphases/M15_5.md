# M15.5 — Dashboard, Metric, Chart, Saved Views

**Fase propietaria:** F15 — Administración visual y DataViews

## Por qué existe
Esta microfase existe para **Dashboard, Metric, Chart, Saved Views** dentro de la responsabilidad de `F15`: resolver Administración con Refine/TanStack. Debe cerrar una capacidad concreta y no abrir un subsystem paralelo.

## Resultado exacto
Al cerrar esta microfase, **Dashboard, Metric, Chart, Saved Views** debe existir como capacidad real, integrada y verificable. No se acepta placeholder ni una implementación paralela al engine.

## Engine owner
`Refine + TanStack + RHF`

### Regla
Antes de escribir código, consulta la API pública del engine. Si ya existe la capacidad, úsala. ElectroCraft solo debe aportar canonical mapping, configuración, UX, adapter, target semantics o exportación.

## Implementación línea por línea
1. Dashboard es un ElectroCraftDocument kind=backend-screen compuesto visualmente; no crea un dashboard runtime separado.
2. Metric se enlaza a saved query/aggregate y renderiza una cifra/label/trend semántico.
3. Chart persiste un `ChartSpec` portable en props y se renderiza mediante `ChartRendererPort`.
4. Web/Studio/React y client-side LAMP/WP usan Apache ECharts adapter; no implementes ejes/escalas/tooltips propios.
5. Native chart renderer se implementa en F22/F22 mediante Victory Native solo cuando dependency compatibility se verifique y Chart esté usado.
6. Cada Chart debe ofrecer accessible title/summary/data fallback; visual chart no es la única forma de comunicar el dato.
7. SavedView serializa únicamente table/filter/view configuration, nunca rows/query cache.
8. RuntimeDependencyManifest incluye chart engine solo si existe Chart en el output.
9. Prueba Metric + Line/Bar/Pie minimal specs, query update, accessible summary, theme change y SavedView isolation.
10. Define AdminScreen/resource semantics.
11. Usa Refine/TanStack para lifecycle/tabla, no reimplementes CRUD.
12. Conecta same DataSource/Permission services.
13. Construye view UI indicada.
14. Prueba CRUD/filters/bulk/permissions/mobile.
