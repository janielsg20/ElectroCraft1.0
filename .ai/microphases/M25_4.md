# M25.4 — Renderer LAMP de pantallas, componentes, temas y assets

**Fase propietaria:** F25 — Exportación LAMP con Slim/PDO

## Por qué existe
LAMP debe conservar el diseño de ElectroCraft sin requerir React por defecto.

## Resultado exacto
Al cerrar esta microfase, **Renderer LAMP de pantallas, componentes, temas y assets** funciona de forma observable dentro del target correspondiente y pasa su gate. No se acepta un archivo generado sin validación ni una opción visual sin compiler/runtime real.

## Engine owner
`ElectroCraft HTML/CSS renderer + Slim/PHP view layer`

## Responsabilidad ElectroCraft
ElectroCraft implementa únicamente el mapping desde modelos canónicos, la UX española, configuración, validación, diagnósticos, seguridad, compilación y evidencia. El framework/SDK target conserva routing/runtime/API behavior que ya ofrece.

## Precondiciones
- Gate de la fase anterior satisfecho.
- ExportIR/TargetRegistry/Capability Analyzer disponibles.
- Tests existentes verdes antes de modificar el target.
- No existe un exporter paralelo para la misma responsabilidad.

## Implementación paso por paso
1. Compile Screen/Documents to semantic HTML/PHP view output.
2. Compile Theme/Tokens/Layout/Style to scoped CSS.
3. Use shared Web renderer mappings where semantics are HTML-compatible, but do not ship React runtime by default.
4. Compile interactive client-only components to minimal generated JS modules.
5. Escape dynamic output at final render boundary.
6. Localize media/assets with stable paths.
7. Generate header/layout/view composition from Navigation/template semantics.
8. Test representative Core components and responsive styles.
9. Compila Routes a Slim, Data a PDO/MySQL y Screens a HTML/PHP.
10. Usa Slim/PSR-7/CSRF/PDO; no infra HTTP/DB propietaria.
11. Genera Composer/migrations/env example.
12. Ejecuta clean install + HTTP/security tests.
13. Empaqueta ZIP y verifica checksum.
