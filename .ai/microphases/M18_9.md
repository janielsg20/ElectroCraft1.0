# M18.9 — Generar modelos, consultas, formularios, workflows, Administración y dashboards

**Fase propietaria:** F18 — Generar con IA — Gemini

## Por qué existe
La IA debe crear también interfaces funcionales y datos/configuración, no solo diseño visual.

## Resultado exacto
Al cerrar esta microfase, **Generar modelos, consultas, formularios, workflows, backend y dashboards** está implementada de extremo a extremo para su alcance y produce evidencia real.

## Engine owner
`ElectroCraftDataSchema/RQB/Form Document/Rete/Refine canonical adapters`

## Responsabilidad ElectroCraft
ElectroCraft controla contratos, contexto, UX en español, permisos, validación, borradores, diff y Apply. El proveedor de IA nunca muta el proyecto directamente.

## Implementación paso por paso
1. Schema generation produces ElectroCraftDataSchema patch with fields/taxonomies/relations/workflow and impact report.
2. Query generation produces ElectroCraftQueryDefinition using allowed field IDs/operators; run RQB diagnostics.
3. Form generation produces ElectroCraftDocument kind=form + formMeta + ActionGraph refs.
4. Workflow generation produces ElectroCraftActionGraph using registered Action nodes only.
5. Admin screen generation produces ElectroCraftDocument kind=backend-screen using Refine admin semantics.
6. Dashboard generation composes Metric/Chart/DataView/Kanban/Calendar according to available queries.
7. Cross-artifact bundle preserves dependency order: schema -> query -> action -> form/backend.
8. Validate permissions/capabilities before preview.
9. Never create provider credentials or secret values.
10. Define request/draft schema antes de prompt/UI.
11. Usa AI SDK para model/tools/structured output y AI Elements para UI estándar.
12. Todas las tools escriben Draft o leen contexto sanitizado.
13. Valida/Preview/Diff antes de Apply.
14. Aplica solo por AIApplyService transaccional.
15. Prueba mock determinista + security + Spanish.
