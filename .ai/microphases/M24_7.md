# M24.7 — Capacitor E2E y paridad

**Fase propietaria:** F24 — Exportación Capacitor

## Por qué existe
El target solo puede considerarse Core cuando pasa el mismo fixture y contrato de paridad que los demás.

## Resultado exacto
Al cerrar esta microfase, **Capacitor E2E y paridad** funciona de forma observable dentro del target correspondiente y pasa su gate. No se acepta un archivo generado sin validación ni una opción visual sin compiler/runtime real.

## Engine owner
`ElectroCraft export verification harness + Capacitor`

## Responsabilidad ElectroCraft
ElectroCraft implementa únicamente el mapping desde modelos canónicos, la UX española, configuración, validación, diagnósticos, seguridad, compilación y evidencia. El framework/SDK target conserva routing/runtime/API behavior que ya ofrece.

## Ubicación de código obligatoria
- `packages/export-capacitor/`
- `packages/export-core/`

## Ubicación exacta en la app
No crea UI nueva; valida `Publicar > Compatibilidad/Exportar > Capacitor`.

## Diseño visual exacto
Usa la app fixture canónica; captura Export Center, compatibility report y runtime smoke.

## Texto visible en español
Paridad; Verificado; Adaptaciones; Bloqueadores; Resultado de pruebas.

## Ayuda contextual
Usa HelpRegistry `help.export.parity`. El H1 usa `CircleHelp`; las opciones técnicas muestran Info solo cuando explican una decisión o requisito del target.

## Precondiciones
- Gate de la fase anterior satisfecho.
- ExportIR/TargetRegistry/Capability Analyzer disponibles.
- Tests existentes verdes antes de modificar el target.
- No existe un exporter paralelo para la misma responsabilidad.

## Implementación paso por paso
1. Exporta la app fixture canónica a Capacitor.
2. Ejecuta Web runtime smoke dentro de shell/plugin fixture.
3. Verifica screens/navigation/data/forms/actions/auth según capability profile.
4. Compara semantic snapshots con expected target adaptations.
5. Verifica no Expo dependency leakage.
6. Verifica Spanish exported app strings where app locale is es.
7. Archive evidence.
8. Reutiliza Web Runtime, no dupliques React exporter.
9. Genera Capacitor config/platform projects.
10. Incluye solo plugins/capabilities usados.
11. Ejecuta sync/build verification.
12. Comprueba no Expo dependency leakage.
13. Registra artifact/report.
