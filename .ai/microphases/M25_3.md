# M25.3 — MySQL/MariaDB schema, migrations y PDO repositories

**Fase propietaria:** F25 — Exportación LAMP con Slim/PDO

## Por qué existe
El target necesita persistencia real y segura para Internal Data sin reusar Postgres syntax ni inventar una ORM propia.

## Resultado exacto
Al cerrar esta microfase, **MySQL/MariaDB schema, migrations y PDO repositories** funciona de forma observable dentro del target correspondiente y pasa su gate. No se acepta un archivo generado sin validación ni una opción visual sin compiler/runtime real.

## Engine owner
`PDO + MySQL/MariaDB`

## Responsabilidad ElectroCraft
ElectroCraft implementa únicamente el mapping desde modelos canónicos, la UX española, configuración, validación, diagnósticos, seguridad, compilación y evidencia. El framework/SDK target conserva routing/runtime/API behavior que ya ofrece.

## Implementación paso por paso
1. Compile internal DataSchema to MySQL/MariaDB migrations.
2. Default generic records/relations/taxonomies/typed index preserves canonical semantics.
3. Allow dedicated-table optimization only behind validated compiler option, never implicit.
4. Generate repository layer using PDO.
5. All values use prepared statements; dynamic identifiers/operators come from compiler allowlists.
6. Generate transaction boundaries for multi-step mutations.
7. Generate migration table/versioning and rollback policy where safe.
8. Test clean install, upgrade, records, relations, facets/index and injection payload.
9. Compila Routes a Slim, Data a PDO/MySQL y Screens a HTML/PHP.
10. Usa Slim/PSR-7/CSRF/PDO; no infra HTTP/DB propietaria.
11. Genera Composer/migrations/env example.
12. Ejecuta clean install + HTTP/security tests.
13. Empaqueta ZIP y verifica checksum.
