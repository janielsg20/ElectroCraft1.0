# M18.5 — AIContextBuilder, privacidad y selección explícita de contexto

**Fase propietaria:** F18 — Generar con IA — Gemini

## Por qué existe
Enviar el proyecto completo a Gemini sería costoso, innecesario y contrario al enfoque local-first/minimal disclosure.

## Resultado exacto
Al cerrar esta microfase, **AIContextBuilder, privacidad y selección explícita de contexto** está implementada de extremo a extremo para su alcance y produce evidencia real.

## Engine owner
`Electro context services + AI SDK model/provider interface`

## Responsabilidad ElectroCraft
ElectroCraft controla contratos, contexto, UX en español, permisos, validación, borradores, diff y Apply. El proveedor de IA nunca muta el proyecto directamente.

## Ubicación de código obligatoria
- `packages/ai/`
- `apps/studio/src/features/ai/`
- `apps/studio/src/components/ai-elements/`

## Ubicación exacta en la app
`Generar con IA > Inspector > Contexto` y modal `Ver lo que se enviará`.

## Diseño visual exacto
Cada contexto es una fila con checkbox, icono, nombre, count/size y Info. Preview de contexto usa Sheet/Modal legible.

## Texto y ayuda
Todo texto visible usa i18n español. El título de la sección lleva `CircleHelp`; las opciones técnicas no obvias usan `Info` con HelpRegistry. Nunca mostrar raw provider errors como texto principal.

## Texto visible en español
Generar con IA; Crear; Historial; Contexto; Opciones; Validación; Generar; Aplicar cambios; Guardar como reutilizable.

## Ayuda contextual
Usa HelpRegistry `help.ai`. Si esta microfase introduce un concepto nuevo, añade/actualiza su HelpDescriptor en español. La ayuda crítica no puede vivir solo en un tooltip.

## Precondiciones
- F17 COMPLETADA: los tipos de artifact reutilizable y ElectroCraftExtensionPackage existen.
- F00 POC Gemini aprobado.
- i18n/HelpRegistry/AppShell disponibles.
- provider secrets fuera del cliente.

## Implementación paso por paso
1. Define context source types: current document, selected nodes, theme/tokens, schema, selected records, reusable library, backend screen, media, user files.
2. Default selecciona solo lo claramente relevante al artifactKind.
3. Build context uses IDs/reference summaries first; include full payload only when needed.
4. Show approximate context size/tokens if provider tokenizer/estimate is available; otherwise label as estimate.
5. `Ver lo que se enviará` renders sanitized structured preview.
6. Sensitive fields/credentials are excluded by permission/schema flags.
7. Provider File Search/context caching remain opt-in because data may persist remotely.
8. User can remove individual context before generation.
9. Prompt injection labels imported/project content as untrusted data in system instructions.
10. Persist only context refs in local history unless full-history preference enabled.
11. Define request/draft schema antes de prompt/UI.
12. Usa AI SDK para model/tools/structured output y AI Elements para UI estándar.
13. Todas las tools escriben Draft o leen contexto sanitizado.
14. Valida/Preview/Diff antes de Apply.
15. Aplica solo por AIApplyService transaccional.
16. Prueba mock determinista + security + Spanish.
