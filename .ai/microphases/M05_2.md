# M05.2 — Componer Components/Outline/Preview/Fields

**Fase propietaria:** F05 — Screen Composer con Puck

## Por qué existe
Esta microfase existe para **Componer Components/Outline/Preview/Fields** dentro de la responsabilidad de `F05`: integrar Puck sin duplicar su editor. Debe cerrar una capacidad concreta y no abrir un subsystem paralelo.

## Resultado exacto
Al cerrar esta microfase, **Componer Components/Outline/Preview/Fields** debe existir como capacidad real, integrada y verificable. No se acepta placeholder ni una implementación paralela al engine.

## Engine owner
`Puck`

### Regla
Antes de escribir código, consulta la API pública del engine. Si ya existe la capacidad, úsala. ElectroCraft solo debe aportar canonical mapping, configuración, UX, adapter, target semantics o exportación.

## Packages/área de código

## Implementación línea por línea
1. Monta `Puck.Components`/Drawer como fuente base de inserción.
2. Monta `Puck.Outline` como outline base.
3. Monta `Puck.Preview` en Canvas.
4. Monta `Puck.Fields` en Inspector > Content.
5. Usa Composition API pública como arquitectura de layout; no reemplaces el shell Puck mediante `overrides`.
6. Para la apariencia de las superficies Puck usa primero las CSS custom properties/design tokens oficiales de la versión pinned; crea un mapping Electro Studio tokens -> Puck theme variables.
7. Usa `syncHostStyles`/iframe styling únicamente según el aislamiento requerido del Canvas; no mezcles accidentalmente Studio theme con project frontend theme.
8. Un override/plugin marcado experimental solo puede cubrir un gap funcional detrás de adapter/feature flag y contract test de fallback; nunca styling básico.
9. No instales Puck AI en core: el editor local no puede depender de Puck Cloud/API keys.
10. No dupliques state/DnD/selection base.
11. Prueba Composition, Puck theme variables, iframe isolation, keyboard insert y click-to-insert Electro.
12. Actualiza mapping ElectroCraftDocument <-> Puck projection.
13. Usa Puck public Composition/Slots/Fields/Outline/Preview en vez de recrearlos.
14. Conecta changes a canonical commands/repository.
15. Mantén history de editor separado de revisions.
16. Prueba round-trip/nesting/selection/history.
