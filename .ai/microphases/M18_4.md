# M18.4 — Pantalla Generar con IA y navegación en español

**Fase propietaria:** F18 — Generar con IA — Gemini

## Por qué existe
La capacidad debe ser fácil de descubrir y usar sin parecer una consola técnica de modelos.

## Resultado exacto
Al cerrar esta microfase, **Pantalla Generar con IA y navegación en español** está implementada de extremo a extremo para su alcance y produce evidencia real.

## Engine owner
`AI Elements + shadcn/ui Radix + @ai-sdk/react + ElectroCraft AI Workbench`

## Responsabilidad ElectroCraft
ElectroCraft controla contratos, contexto, UX en español, permisos, validación, borradores, diff y Apply. El proveedor de IA nunca muta el proyecto directamente.

## Ubicación de código obligatoria
- `packages/ai/`
- `apps/studio/src/features/ai/`
- `apps/studio/src/components/ai-elements/`

## Ubicación exacta en la app
Sidebar `Construir > Generar con IA` inmediatamente después de `Componentes`. Icono `Sparkles`.

## Diseño visual exacto
Reutiliza AppShell: Context 288 con Crear/Historial; centro Workbench; Inspector 320 Contexto/Opciones/Validación. Topbar global no cambia.

## Texto y ayuda
Todo texto visible usa i18n español. El título de la sección lleva `CircleHelp`; las opciones técnicas no obvias usan `Info` con HelpRegistry. Nunca mostrar raw provider errors como texto principal.

## Texto visible en español
Generar con IA; Crear; Historial; Contexto; Opciones; Validación; Generar; Aplicar cambios; Guardar como reutilizable.

## Ayuda contextual
Usa HelpRegistry `help.ai`. Si esta microfase introduce un concepto nuevo, añade/actualiza su HelpDescriptor en español. La ayuda crítica no puede vivir solo en un tooltip.

## Precondiciones
- F17 COMPLETADA: los tipos de artifact reutilizable y ElectroCraftExtensionPackage existen.
- F00 POC Gemini aprobado.
- i18n/HelpRegistry/AppShell disponibles.
- provider secrets fuera del cliente.

## Implementación paso por paso
1. Instala solo los AI Elements necesarios según docs/version actuales: Conversation, Message/MessageResponse, Prompt Input, Tool, Plan y CodeBlock solo si realmente se usa.
2. No instales `all` ni componentes React Flow Node/Canvas, porque Rete ya es el workflow graph owner.
3. Implementa route `Construir > Generar con IA` con Context 288 / Workbench flex / Inspector 320.
4. Usa Conversation/Message para streaming y MessageResponse para texto/Markdown generado.
5. Usa Tool para estados de tool calls y Plan para plan estructurado cuando se muestre al usuario.
6. ElectroCraft implementa sus propias tabs `Conversación | Vista previa | Cambios`, porque Preview/Diff/Apply son semántica del producto.
7. Composer usa Prompt Input integrado con attachments/context trigger y botón Generar/Cancelar.
8. Traduce/override cualquier copy por i18n; cero labels inglesas.
9. Lazy-load AI workspace y sus dependencias al abrir la ruta.
10. Añade mobile wizard y keyboard/focus behavior.
11. Test streaming, tool states, long Markdown, cancel, empty/error/offline and Spanish.
12. Define request/draft schema antes de prompt/UI.
13. Usa AI SDK para model/tools/structured output y AI Elements para UI estándar.
14. Todas las tools escriben Draft o leen contexto sanitizado.
15. Valida/Preview/Diff antes de Apply.
16. Aplica solo por AIApplyService transaccional.
17. Prueba mock determinista + security + Spanish.
