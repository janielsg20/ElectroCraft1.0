# M06.2 — Responsive inheritance y reset

**Fase propietaria:** F06 — Layout, responsive y edición avanzada

## Por qué existe
Esta microfase existe para **Responsive inheritance y reset** dentro de la responsabilidad de `F06`: añadir capacidades avanzadas/responsive sobre Puck. Debe cerrar una capacidad concreta y no abrir un subsystem paralelo.

## Resultado exacto
Al cerrar esta microfase, **Responsive inheritance y reset** debe existir como capacidad real, integrada y verificable. No se acepta placeholder ni una implementación paralela al engine.

## Engine owner
`Puck extensions + Electro layout/style`

### Regla
Antes de escribir código, consulta la API pública del engine. Si ya existe la capacidad, úsala. ElectroCraft solo debe aportar canonical mapping, configuración, UX, adapter, target semantics o exportación.

## Implementación línea por línea
1. Define presets Desktop, Laptop, Tablet landscape, Tablet portrait, Mobile large y Mobile small, además de custom breakpoints.
2. El modelo canónico usa base + overrides por breakpoint; no duplica documentos.
3. Mapea los breakpoints visibles del Studio a la configuración `viewports` pública de Puck para el frame de preview.
4. Cambiar viewport Puck/Topbar NO debe crear un override por sí mismo.
5. Inspector muestra source: Base / Inherited from X / Override here.
6. `Override` escribe solo la propiedad actual; `Reset` elimina el override.
7. Permite editar width y crear/renombrar custom breakpoint IDs estables.
8. Preview portrait/landscape modifica frame/orientation, no canonical content.
9. Prueba que custom breakpoint round-trip se conserva aunque Puck tenga un conjunto de viewports distinto internamente.
10. Extiende canonical Layout/Style/Responsive metadata.
11. Implementa overlay/control solo para gap no cubierto por Puck.
12. Conecta Inspector/Canvas sin almacenar transient geometry innecesaria.
13. Añade keyboard alternative a pointer interaction.
14. Prueba desktop/tablet/mobile y target diagnostics.
