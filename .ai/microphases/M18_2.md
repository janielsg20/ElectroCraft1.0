# M18.2 — Gemini con @ai-sdk/google y escape hatch nativo mínimo

**Fase propietaria:** F18 — Generar con IA — Gemini

## Por qué existe
Gemini es el proveedor principal y necesita un adapter estable que absorba cambios de modelos/API sin contaminar ElectroCraft.

## Resultado exacto
Al cerrar esta microfase, **@ai-sdk/google provider con @google/genai e Interactions API** está implementada de extremo a extremo para su alcance y produce evidencia real.

## Engine owner
`Vercel AI SDK + @ai-sdk/google; @google/genai solo como capability escape hatch`

## Responsabilidad ElectroCraft
ElectroCraft controla contratos, contexto, UX en español, permisos, validación, borradores, diff y Apply. El proveedor de IA nunca muta el proyecto directamente.

## Ubicación de código obligatoria
- `packages/ai/`
- `apps/studio/src/features/ai/`
- `apps/studio/src/components/ai-elements/`

## Ubicación exacta en la app
Configuración avanzada vive en `Configuración > IA > Proveedores`; el usuario normal usa Modo Automático en Generar con IA.

## Diseño visual exacto
Provider card: Gemini, estado Conectado/No configurado/Error, modelo resuelto solo en Advanced.

## Texto y ayuda
Todo texto visible usa i18n español. El título de la sección lleva `CircleHelp`; las opciones técnicas no obvias usan `Info` con HelpRegistry. Nunca mostrar raw provider errors como texto principal.

## Texto visible en español
Generar con IA; Crear; Historial; Contexto; Opciones; Validación; Generar; Aplicar cambios; Guardar como reutilizable.

## Ayuda contextual
Usa HelpRegistry `help.ai`. Si esta microfase introduce un concepto nuevo, añade/actualiza su HelpDescriptor en español. La ayuda crítica no puede vivir solo en un tooltip.

## Precondiciones
- F17 COMPLETADA: los tipos de artifact reutilizable y ElectroCraftExtensionPackage existen.
- F00 POC Gemini aprobado.
- i18n/HelpRegistry/AppShell disponibles.
- provider secrets fuera del cliente.

## Implementación paso por paso
1. Instala/configura AI SDK según la versión oficial pinned y el provider Google correspondiente.
2. Implementa `AIModelProfileResolver` para traducir Automático/Rápido/Calidad/Imagen a modelos Gemini verificados.
3. Structured generation, streaming y tool orchestration pasan por AI SDK.
4. No crees `@ai-sdk/google provider` si `@ai-sdk/google` ya cubre la necesidad.
5. Ejecuta capability POC para imagen avanzada/grounding/Interactions.
6. Solo si falta una capacidad requerida, crea `GeminiNativeCapabilityAdapter` con el método exacto faltante; no replica text/tools/streaming.
7. Normaliza errores Google/AI SDK a `AIProviderErrorCode`.
8. Actual model ID se guarda solo como metadata de sesión/diagnóstico.
9. Revalida model deprecation/fallback al iniciar/probar conexión.
10. Prueba provider unavailable, model retired, structured schema limitation, cancel y fallback.
11. Define request/draft schema antes de prompt/UI.
12. Usa AI SDK para model/tools/structured output y AI Elements para UI estándar.
13. Todas las tools escriben Draft o leen contexto sanitizado.
14. Valida/Preview/Diff antes de Apply.
15. Aplica solo por AIApplyService transaccional.
16. Prueba mock determinista + security + Spanish.
