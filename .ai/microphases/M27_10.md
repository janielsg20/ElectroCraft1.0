# M27.10 — Paridad Proyecto local / React / Estático / PWA

**Fase propietaria:** F27 — Hardening, paridad de exportación y release

## Por qué existe
Esta microfase existe para **Web/React/PWA equivalence** dentro de la responsabilidad de `F27`: demostrar equivalencia/cobertura/release. Debe cerrar una capacidad concreta y no abrir un subsystem paralelo.

## Resultado exacto
Al cerrar esta microfase, **Web/React/PWA equivalence** debe existir como capacidad real, integrada y verificable. No se acepta placeholder ni una implementación paralela al engine.

## Implementación línea por línea
1. Exporta exactamente la misma revision canónica a Proyecto local, React Web, Sitio estático y PWA.
2. Verifica Local ZIP + checksum + reimport.
3. Verifica React install/typecheck/build.
4. Verifica Static generated files/local serve and expected blockers for dynamic-only features.
5. Verifica PWA build/manifest/service worker/offline behavior.
6. Compara Screens, Navigation, Theme, Data, Forms, Actions and Permissions where target supports them.
7. Cada adaptación/bloqueo debe coincidir con Compatibility report previo.
8. No aceptes una diferencia no registrada en ExportParityMatrix.
9. Registra artifacts/checksums/build logs.
10. Cierra solo con los cuatro targets evaluados.
11. Ejecuta la fixture canónica, no una demo alternativa.
12. Corre gate específico solicitado sobre todo el sistema.
13. Reabre owner microphase ante gap P0/P1.
14. Actualiza matrices/evidence con paths reales.
15. No compenses un target fallido con otro.
16. Cierra release solo con evidencia coherente.
