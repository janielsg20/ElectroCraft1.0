# M21.4 — Web Runtime dependency pruning pre-export

**Fase propietaria:** F21 — Runtime Web y exportación React/PWA

## Por qué existe
El runtime debe conocer qué paquetes realmente necesita antes de escribir package.json.

## Resultado exacto
Al cerrar esta microfase, **Web Runtime dependency pruning pre-export** existe como capacidad real, conectada a los contratos de ElectroCraft y demostrada con pruebas. No se acepta placeholder, botón decorativo ni contrato sin consumidor.

## Engine owner
`RuntimeDependencyManifest`

## Responsabilidad ElectroCraft
ElectroCraft conserva únicamente la semántica portable, la UX española, los adapters, permisos, validación, persistencia y compatibilidad multi-target. El engine OSS conserva la responsabilidad técnica para la que fue elegido.

## Ubicación de código obligatoria
- `packages/runtime-web/`
- `packages/export-web/`
- `packages/export-core/`

## Ubicación exacta en la app
`Publicar > Exportar > Dependencias` Advanced.

## Diseño visual exacto
Lista dependency + motivo/capability + target; warning para dependencias Studio filtradas.

## Texto visible en español
Dependencias; Motivo; Necesaria; Eliminada; Solo Studio.

## Ayuda contextual
Usa HelpRegistry `help.export.dependencies`. El título de pantalla lleva `CircleHelp`; los conceptos técnicos usan `Info` solo cuando aportan contexto real.

## Precondiciones
- Gate de entrada de la fase satisfecho.
- Contratos/engines anteriores verdes.
- No existe una implementación paralela de la misma responsabilidad.

## Implementación paso por paso
1. Escanea ExportIR/component/query/action/source capabilities.
2. Construye manifest para Web runtime.
3. Marca Studio-only Puck/Rete editor/AI workbench como excluded.
4. Incluye Refine solo si existen admin screens exportadas.
5. Incluye connector runtime solo si una source lo necesita.
6. Prueba fixture mínimo vs app completa.
7. Congela ExportIR revision.
8. Genera runtime/source mediante shared Web compilers.
9. Genera target-specific package/profile.
10. Ejecuta dependency pruning.
11. Ejecuta install/build/serve/reimport verifier según target.
12. Registra artifact/checksum/report.
