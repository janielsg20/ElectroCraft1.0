# M18.3 — AIGateway seguro, credenciales y configuración de IA

**Fase propietaria:** F18 — Generar con IA — Gemini

## Por qué existe
Google recomienda no exponer API keys en cliente; la app debe funcionar con un gateway seguro y seguir local-first cuando la IA no está configurada.

## Resultado exacto
Al cerrar esta microfase, **AIGateway seguro, credenciales y configuración de IA** está implementada de extremo a extremo para su alcance y produce evidencia real.

## Engine owner
`Server/local gateway + secret store adapter`

## Responsabilidad ElectroCraft
ElectroCraft controla contratos, contexto, UX en español, permisos, validación, borradores, diff y Apply. El proveedor de IA nunca muta el proyecto directamente.

## Ubicación de código obligatoria
- `packages/ai/`
- `apps/studio/src/features/ai/`
- `apps/studio/src/components/ai-elements/`

## Ubicación exacta en la app
`Configuración > IA`. Categorías: Proveedor, Conexión, Privacidad, Límites, Herramientas.

## Diseño visual exacto
Sheet Settings existente. Form rows compactas; secret fields nunca muestran valor completo. Status card arriba.

## Texto y ayuda
Todo texto visible usa i18n español. El título de la sección lleva `CircleHelp`; las opciones técnicas no obvias usan `Info` con HelpRegistry. Nunca mostrar raw provider errors como texto principal.

## Texto visible en español
Generar con IA; Crear; Historial; Contexto; Opciones; Validación; Generar; Aplicar cambios; Guardar como reutilizable.

## Ayuda contextual
Usa HelpRegistry `help.ai`. Si esta microfase introduce un concepto nuevo, añade/actualiza su HelpDescriptor en español. La ayuda crítica no puede vivir solo en un tooltip.

## Precondiciones
- F17 COMPLETADA: los tipos de artifact reutilizable y ElectroCraftExtensionPackage existen.
- F00 POC Gemini aprobado.
- i18n/HelpRegistry/AppShell disponibles.
- provider secrets fuera del cliente.

## Implementación paso por paso
1. Define `AIGatewayPort` y request envelope autenticado por la sesión del Studio cuando corresponda.
2. Implementa gateway reference para desarrollo local/serverless/hosted; no acoples a un vendor deployment.
3. Secrets se resuelven server-side/env/secret store y nunca se serializan en project/workspace exports.
4. Pantalla muestra `Gemini: No configurado|Conectado|Error` y botón `Probar conexión`.
5. Configura privacy defaults: minimal context, history metadata-only, web search off, file search off.
6. Configura optional generation limits y warning threshold.
7. Implementa offline state y provider-disabled state.
8. Test bundle/source scan para GEMINI_API_KEY/API key patterns.
9. Documenta deployment adapters para gateway sin hacer Deploy obligatorio.
10. Define request/draft schema antes de prompt/UI.
11. Usa AI SDK para model/tools/structured output y AI Elements para UI estándar.
12. Todas las tools escriben Draft o leen contexto sanitizado.
13. Valida/Preview/Diff antes de Apply.
14. Aplica solo por AIApplyService transaccional.
15. Prueba mock determinista + security + Spanish.
