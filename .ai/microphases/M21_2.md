# M21.2 — Web Router compiler y navegación

**Fase propietaria:** F21 — Runtime Web y exportación React/PWA

## Por qué existe
Las Pantallas deben convertirse en una navegación Web real con rutas, params y guards.

## Resultado exacto
Al cerrar esta microfase, **Web Router compiler y navegación** existe como capacidad real, conectada a los contratos de ElectroCraft y demostrada con pruebas. No se acepta placeholder, botón decorativo ni contrato sin consumidor.

## Engine owner
`React Router adapter/compiler`

## Responsabilidad ElectroCraft
ElectroCraft conserva únicamente la semántica portable, la UX española, los adapters, permisos, validación, persistencia y compatibilidad multi-target. El engine OSS conserva la responsabilidad técnica para la que fue elegido.

## Ubicación de código obligatoria
- `packages/runtime-web/`
- `packages/export-web/`
- `packages/export-core/`

## Ubicación exacta en la app
`Vista previa Web` y export React consumen el routing generado.

## Diseño visual exacto
No UI nueva; las definiciones se editan en `App > Navegación` y se prueban en Vista previa.

## Texto visible en español
Ruta; Navegar; Atrás; No encontrado.

## Ayuda contextual
Usa HelpRegistry `help.navigation.runtime`. El título de pantalla lleva `CircleHelp`; los conceptos técnicos usan `Info` solo cuando aportan contexto real.

## Precondiciones
- Gate de entrada de la fase satisfecho.
- Contratos/engines anteriores verdes.
- No existe una implementación paralela de la misma responsabilidad.

## Implementación paso por paso
1. Compila ElectroCraftRoutes/Navigation a React Router route definitions/source.
2. Mapea screen route, params, nested layouts y 404.
3. Implementa Navigation actions go/back/replace/openExternal.
4. Aplica route guards mediante Auth/Permission contracts.
5. Prueba deep links, params, protected route y 404.
6. Congela ExportIR revision.
7. Genera runtime/source mediante shared Web compilers.
8. Genera target-specific package/profile.
9. Ejecuta dependency pruning.
10. Ejecuta install/build/serve/reimport verifier según target.
11. Registra artifact/checksum/report.
