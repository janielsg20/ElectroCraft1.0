# M25.2 — Runtime Slim 4, routing y middleware

**Fase propietaria:** F25 — Exportación LAMP con Slim/PDO

## Por qué existe
ElectroCraft no debe reimplementar routing, request/response, middleware y error dispatch que Slim ya ofrece.

## Resultado exacto
Al cerrar esta microfase, **Runtime Slim 4, routing y middleware** funciona de forma observable dentro del target correspondiente y pasa su gate. No se acepta un archivo generado sin validación ni una opción visual sin compiler/runtime real.

## Engine owner
`Slim Framework 4 + PSR-7`

## Responsabilidad ElectroCraft
ElectroCraft implementa únicamente el mapping desde modelos canónicos, la UX española, configuración, validación, diagnósticos, seguridad, compilación y evidencia. El framework/SDK target conserva routing/runtime/API behavior que ya ofrece.

## Implementación paso por paso
1. Genera front controller public/index.php.
2. Genera Composer dependencies Slim + approved PSR-7.
3. Compile ElectroCraftRouteDefinition to named Slim routes/groups.
4. Compile route guards to middleware refs.
5. Configure routing/error middleware order according to Slim public APIs.
6. Production generated config disables detailed error output.
7. Generate controllers as thin HTTP adapters calling application services.
8. Add 404/405/error handlers and route cache strategy when justified.
9. Test params, methods, 404, guard and exception normalization.
10. Compila Routes a Slim, Data a PDO/MySQL y Screens a HTML/PHP.
11. Usa Slim/PSR-7/CSRF/PDO; no infra HTTP/DB propietaria.
12. Genera Composer/migrations/env example.
13. Ejecuta clean install + HTTP/security tests.
14. Empaqueta ZIP y verifica checksum.
