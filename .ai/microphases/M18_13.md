# M18.13 — Historial, prompts reutilizables, límites, cancelación y privacidad

**Fase propietaria:** F18 — Generar con IA — Gemini

## Por qué existe
La sección necesita ser usable en proyectos reales sin acumular datos privados ni dejar generaciones incontrolables.

## Resultado exacto
Al cerrar esta microfase, **Historial, prompts reutilizables, límites, cancelación y privacidad** está implementada de extremo a extremo para su alcance y produce evidencia real.

## Engine owner
`PGlite Studio data + AIProvider cancellation/usage`

## Responsabilidad ElectroCraft
ElectroCraft controla contratos, contexto, UX en español, permisos, validación, borradores, diff y Apply. El proveedor de IA nunca muta el proyecto directamente.

## Ubicación de código obligatoria
- `packages/ai/`
- `apps/studio/src/features/ai/`
- `apps/studio/src/components/ai-elements/`

## Ubicación exacta en la app
`Generar con IA > Historial` y `Configuración > IA > Privacidad/Límites`.

## Diseño visual exacto
History list compact with search/filter/status. Prompt presets are saved separately and clearly labeled; no chat-app clutter.

## Texto y ayuda
Todo texto visible usa i18n español. El título de la sección lleva `CircleHelp`; las opciones técnicas no obvias usan `Info` con HelpRegistry. Nunca mostrar raw provider errors como texto principal.

## Texto visible en español
Generar con IA; Crear; Historial; Contexto; Opciones; Validación; Generar; Aplicar cambios; Guardar como reutilizable.

## Ayuda contextual
Usa HelpRegistry `help.ai`. Si esta microfase introduce un concepto nuevo, añade/actualiza su HelpDescriptor en español. La ayuda crítica no puede vivir solo en un tooltip.

## Implementación paso por paso
1. Create ai_generation_sessions, ai_artifact_drafts, ai_usage_events, ai_prompt_presets migrations.
2. Retention settings: none, metadata-only, full-local.
3. Prompt preset saves user prompt template and expected artifactKind/context policy, not provider secret.
4. Display token/usage stats returned by provider; no invented monetary cost.
5. Implement cancel with provider Abort/cancel path and status Cancelado.
6. Implement timeout/retry policy without duplicate Apply.
7. Implement generation limits/warnings configured by user.
8. Delete history removes local prompt/context copy and draft per policy.
9. Provider interaction continuation ID is optional and cleared when history is deleted.
10. Offline history remains browseable.
11. Define request/draft schema antes de prompt/UI.
12. Usa AI SDK para model/tools/structured output y AI Elements para UI estándar.
13. Todas las tools escriben Draft o leen contexto sanitizado.
14. Valida/Preview/Diff antes de Apply.
15. Aplica solo por AIApplyService transaccional.
16. Prueba mock determinista + security + Spanish.
