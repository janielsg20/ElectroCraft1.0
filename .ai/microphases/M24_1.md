# M24.1 — Descriptor del target Capacitor y configuración

**Fase propietaria:** F24 — Exportación Capacitor

## Por qué existe
Capacitor debe ser una exportación Core con identidad, configuración, compiler y verifier propios.

## Resultado exacto
Al cerrar esta microfase, **Descriptor del target Capacitor y configuración** funciona de forma observable dentro del target correspondiente y pasa su gate. No se acepta un archivo generado sin validación ni una opción visual sin compiler/runtime real.

## Engine owner
`Capacitor official config/CLI + ExportTargetRegistry`

## Responsabilidad ElectroCraft
ElectroCraft implementa únicamente el mapping desde modelos canónicos, la UX española, configuración, validación, diagnósticos, seguridad, compilación y evidencia. El framework/SDK target conserva routing/runtime/API behavior que ya ofrece.

## Ubicación de código obligatoria
- `packages/export-capacitor/`
- `packages/export-core/`

## Ubicación exacta en la app
`Publicar > Exportar > Capacitor`.

## Diseño visual exacto
Export Center estándar. Config central: Aplicación, Web Runtime, Plataformas, Plugins, Permisos, Build. Panel derecho muestra compatibilidad exacta.

## Texto visible en español
Capacitor; Aplicación; Android; iOS; Web Runtime; Plugins; Permisos; Analizar; Generar.

## Ayuda contextual
Usa HelpRegistry `help.export.capacitor`. El H1 usa `CircleHelp`; las opciones técnicas muestran Info solo cuando explican una decisión o requisito del target.

## Precondiciones
- Gate de la fase anterior satisfecho.
- ExportIR/TargetRegistry/Capability Analyzer disponibles.
- Tests existentes verdes antes de modificar el target.
- No existe un exporter paralelo para la misma responsabilidad.

## Implementación paso por paso
1. Registra `capacitor` en TargetRegistry con `core=true` y sin campos de prioridad.
2. Define config schema: appId, appName, webDir, server disabled by default, Android/iOS toggles, environment refs.
3. Deriva appId/bundle naming desde project settings con validation y override explícito.
4. Define artifact kinds: source zip, Android project, iOS project, build artifacts when available.
5. Define toolchain requirements without turning missing local SDKs into fake blockers for source generation.
6. Añade destination card y HelpDescriptor español.
7. Añade TargetDescriptor contract tests.
8. Reutiliza Web Runtime, no dupliques React exporter.
9. Genera Capacitor config/platform projects.
10. Incluye solo plugins/capabilities usados.
11. Ejecuta sync/build verification.
12. Comprueba no Expo dependency leakage.
13. Registra artifact/report.
