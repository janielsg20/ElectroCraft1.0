# M07.4 — Navigation Builder UX

**Fase propietaria:** F07 — Pantallas, navegación y rutas

## Por qué existe
La navegación compleja debe poder configurarse sin editar rutas manualmente.

## Resultado exacto
Al cerrar esta microfase, **Navigation Builder UX** existe como capacidad real, conectada a los contratos de ElectroCraft y demostrada con pruebas. No se acepta placeholder, botón decorativo ni contrato sin consumidor.

## Engine owner
`ElectroCraftNavigation + shadcn/ui`

## Responsabilidad ElectroCraft
ElectroCraft conserva únicamente la semántica portable, la UX española, los adapters, permisos, validación, persistencia y compatibilidad multi-target. El engine OSS conserva la responsabilidad técnica para la que fue elegido.

## Ubicación de código obligatoria
- `packages/domain/src/navigation/`
- `packages/application/src/navigation/`
- `apps/studio/src/features/navigation/`

## Ubicación exacta en la app
`App > Navegación`.

## Diseño visual exacto
Desktop: navigator tree 300 izquierda, live structure center, inspector 320. No usar graph canvas si un tree ordenable resuelve la tarea.

## Texto visible en español
Navegación; Agregar navegador; Pila; Pestañas; Menú lateral; Modal; Pantalla; Reordenar; Pantalla inicial.

## Ayuda contextual
Usa HelpRegistry `help.navigation.builder`. El título de pantalla lleva `CircleHelp`; los conceptos técnicos usan `Info` solo cuando aportan contexto real.

## Precondiciones
- Gate de entrada de la fase satisfecho.
- Contratos/engines anteriores verdes.
- No existe una implementación paralela de la misma responsabilidad.

## Implementación paso por paso
1. Implementa tree editor para navigator nodes.
2. Drag/reorder tiene keyboard Move up/down alternative.
3. Inspector cambia label/icon/header/back behavior per node.
4. Tabs config icon/label/visibility; Drawer config side/width per target capability.
5. Modal screen config presentation semantics.
6. Añade preview diagram simple derivado del tree, no segundo data model.
7. Prueba nested stack+tabs, reorder, keyboard, mobile settings sheet.
8. Actualiza Navigation/Route contracts primero.
9. Implementa use-case/ref integrity.
10. Construye tree editor español.
11. Añade target compiler contract fixture sin persistir router objects.
12. Prueba params/deep-links/guards/ref rename.

## Artefactos obligatorios al cerrar
- `NavigationBuilder`
- `navigation tree tests`

## Estados UI obligatorios
- Inicial.
- Cargando, solo cuando haya espera perceptible.
- Vacío con explicación y CTA.
- Error en español con recuperación.
- Deshabilitado con motivo.
- Guardando/Aplicando cuando corresponda.
- Éxito breve y accionable.

## Responsive
- Desktop: alta densidad sin comprimir la tarea principal.
- Tablet: panel secundario a Sheet/Drawer.
- Mobile: flujo por rutas/pasos; no reducir una UI desktop de tres columnas.

## Accesibilidad
- teclado;
- focus-visible;
- labels persistentes;
- icon-only con aria-label;
- errores anunciables;
- touch targets;
- reduced motion;
- alternativa a drag cuando aplique.
