# M25.6 — State, Actions, Auth, Permissions y Administración LAMP

**Fase propietaria:** F25 — Exportación LAMP con Slim/PDO

## Por qué existe
Estas capacidades no pueden convertirse en placeholders solo porque el target no usa React/Expo.

## Resultado exacto
Al cerrar esta microfase, **State, Actions, Auth, Permissions y Administración LAMP** funciona de forma observable dentro del target correspondiente y pasa su gate. No se acepta un archivo generado sin validación ni una opción visual sin compiler/runtime real.

## Engine owner
`Slim middleware/services + PHP sessions + ElectroCraft target compilers`

## Responsabilidad ElectroCraft
ElectroCraft implementa únicamente el mapping desde modelos canónicos, la UX española, configuración, validación, diagnósticos, seguridad, compilación y evidencia. El framework/SDK target conserva routing/runtime/API behavior que ya ofrece.

## Implementación paso por paso
1. Map State scopes explicitly between PHP request/session/DB and client JS; emit blocker for unsupported semantics.
2. Compile server Action nodes to application handlers and client UI actions to generated JS; cross boundary through typed endpoints.
3. Generate login/logout/session restore with password_hash/password_verify strategy and secure cookies.
4. Compile PermissionPolicy to middleware + service checks.
5. Generate Administration routes/views using target-specific HTML/PHP DataViews; Refine is Studio authoring only and is not shipped.
6. Compile Audit events where project uses audit.
7. Test auth, route deny, field/action permission, session state, admin CRUD and workflow execution.
8. Compila Routes a Slim, Data a PDO/MySQL y Screens a HTML/PHP.
9. Usa Slim/PSR-7/CSRF/PDO; no infra HTTP/DB propietaria.
10. Genera Composer/migrations/env example.
11. Ejecuta clean install + HTTP/security tests.
12. Empaqueta ZIP y verifica checksum.
