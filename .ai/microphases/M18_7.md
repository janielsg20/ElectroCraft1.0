# M18.7 — AIToolRegistry sobre AI SDK tools, solo lectura y borradores

**Fase propietaria:** F18 — Generar con IA — Gemini

## Por qué existe
Gemini function calling es útil para iterar, pero las herramientas deben estar allowlisted y limitadas a lectura o DraftWorkspace.

## Resultado exacto
Al cerrar esta microfase, **AIToolRegistry y function calling solo sobre borradores** está implementada de extremo a extremo para su alcance y produce evidencia real.

## Engine owner
`Vercel AI SDK tools/ToolLoopAgent + ElectroCraft AIToolRegistry`

## Responsabilidad ElectroCraft
ElectroCraft controla contratos, contexto, UX en español, permisos, validación, borradores, diff y Apply. El proveedor de IA nunca muta el proyecto directamente.

## Ubicación de código obligatoria
- `packages/ai/`
- `apps/studio/src/features/ai/`
- `apps/studio/src/components/ai-elements/`

## Ubicación exacta en la app
Tool calls aparecen como filas de progreso traducidas: `Leyendo componentes`, `Creando borrador de página`, `Validando cambios`.

## Diseño visual exacto
No mostrar nombres internos de funciones en UI beginner; Debug puede verlos.

## Texto y ayuda
Todo texto visible usa i18n español. El título de la sección lleva `CircleHelp`; las opciones técnicas no obvias usan `Info` con HelpRegistry. Nunca mostrar raw provider errors como texto principal.

## Texto visible en español
Generar con IA; Crear; Historial; Contexto; Opciones; Validación; Generar; Aplicar cambios; Guardar como reutilizable.

## Ayuda contextual

## Implementación paso por paso
1. Define AI SDK tools exclusivamente desde `AI_TOOL_CATALOG.md`.
2. Cada tool usa input schema tipado/Zod.
3. `activeTools`/equivalente limita herramientas según artifactKind y permisos de la solicitud.
4. Read tools pasan por application services sanitizados, no por raw DB.
5. Draft tools escriben únicamente AIDraftWorkspace.
6. Tool execution valida nombre, input, permission, size y context allowance.
7. Configura step limit/stop condition y timeout.
8. Usa ToolLoopAgent solo para tareas que realmente necesitan interacción iterativa; artifact workflow determinista puede ejecutar tools explícitamente.
9. Rechaza unknown tool, bad input, unauthorized read y loop exhaustion.
10. Nunca registres Apply/DB/SQL/File/Install/Deploy/Secret/CodeExec como tool.
11. Define request/draft schema antes de prompt/UI.
12. Usa AI SDK para model/tools/structured output y AI Elements para UI estándar.
13. Todas las tools escriben Draft o leen contexto sanitizado.
14. Valida/Preview/Diff antes de Apply.
15. Aplica solo por AIApplyService transaccional.
16. Prueba mock determinista + security + Spanish.
