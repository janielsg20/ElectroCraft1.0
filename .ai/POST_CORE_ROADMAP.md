# POST-CORE ROADMAP

Post-Core items must not include any of the nine export destinations.

Possible later work:
- additional Data Source connectors;
- additional AI providers/local models through AI SDK;
- advanced Code Mode with real sandbox;
- Yjs collaboration;
- public arbitrary-code extension SDK;
- desktop/Tauri target only if formally added later through Export Target Contract;
- more deployment-provider integrations.

Current export destinations are already Core:
Local, React, Static, PWA, Android, iOS, Capacitor, LAMP, WordPress.
