# SPANISH UI COPY SPEC

## Voz
- clara;
- directa;
- profesional;
- no infantil;
- orientada a la acción;
- término de usuario primero, término técnico después.

## Botones
Verbo + objeto cuando sea ambiguo:
- Crear página
- Nueva consulta
- Generar con IA
- Aplicar cambios
- Guardar como bloque
- Revisar compatibilidad
- Exportar proyecto

Evitar:
- OK
- Sí
- Submit
- Go
si no explican la acción.

## Estados
- Guardando…
- Guardado
- Sin cambios pendientes
- No hay resultados
- Requiere revisión
- No compatible
- Adaptación disponible
- Sin conexión
- Proveedor de IA no configurado

## Errores
Formato:
1. qué pasó;
2. qué puede hacer el usuario;
3. detalle técnico solo expandible.

Ejemplo:
`No se pudo ejecutar la consulta. Revisa el campo Precio o vuelve a intentarlo.`
Detalle:
`QUERY_FIELD_MISSING: product.price`

## Conceptos
`Modelo de contenido`
Ayuda: «Define la estructura de un tipo de información, por ejemplo Productos, Propiedades o Citas.»

`Consulta`
Ayuda: «Selecciona y ordena datos para mostrarlos en listas, filtros, paneles o formularios.»

`Relación`
Ayuda: «Conecta registros entre sí, por ejemplo un Agente con muchas Propiedades.»

`Extensión`
Ayuda: «Paquete reutilizable que añade bloques, pantallas, modelos, acciones u otras capacidades.»

`Proyecto preconfigurado`
Ayuda: «Conjunto listo de estructura, diseño y funciones para empezar un tipo de proyecto.»

## IA
No usar:
`La IA hizo cambios`
si todavía son borradores.

Usar:
- Borrador generado
- Revisar cambios
- Aplicar al proyecto
- Descartar borrador
- Requiere revisión de código
