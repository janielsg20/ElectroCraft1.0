# EVIDENCE

Store real verification only:
- command logs;
- test summaries;
- screenshots when a UI gate requires them;
- generated artifact checksums;
- package dependency reports;
- compatibility reports;
- benchmark results.

Naming:
`<phase>-<microphase>-<kind>-<YYYYMMDD-HHMM>.*`

Never invent or hand-write a passing log.
