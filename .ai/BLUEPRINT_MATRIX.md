All use one installer and the same ElectroCraft primitives.

Every template declares:
- Screens;
- Navigation;
- Data Models/Data Sources;
- Queries;
- State;
- Actions/Workflows;
- Forms;
- Administration;
- Roles;
- Theme;
- optional demo data.

No template ships its own engine/runtime architecture.
