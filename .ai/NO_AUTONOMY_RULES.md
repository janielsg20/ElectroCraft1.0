# NO-AUTONOMY RULES — ElectroCraft Eighth Final

Before coding classify responsibility.

## Studio primitive
Does current shadcn Radix already provide it?

## AI UI
Does a selected AI Elements component provide the standard message/conversation/prompt/tool/plan behavior?

## Visual Editor
Does Puck own it?

## Data
Is it DataSource/Query/Binding?

## Admin
Does Refine/TanStack own it?

## Forms
Does RHF/Zod own it for JS targets?

## Workflow
Does Rete own the graph/history/JS flow?

## Rich Text
Does Tiptap own it?

## State
Does Zustand own JS runtime mechanics?

## AI orchestration
Does AI SDK own provider/tool/streaming behavior?

## Target export
Does it belong to the shared Export Target Contract and a target compiler rather than a new canonical model?

## LAMP
Can Slim/PDO/Slim-CSRF provide routing/DB/CSRF before creating custom infrastructure?

## WordPress
Can a native WP block/theme/content/REST/user/media API provide it before creating custom plugin infrastructure?

## Capacitor
Can an official/approved plugin provide it before custom bridge code?

A new subsystem requires ADR proving:
gap, owner, persistence, UI location, target impact, security, migrations, rollback and why existing OSS/adapters cannot solve it.
