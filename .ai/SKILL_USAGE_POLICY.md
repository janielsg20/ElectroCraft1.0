# SKILL USAGE POLICY — ElectroCraft

# UI
Before implementing/auditing Studio UI:
- invoke shadcn skill;
- use available UI/UX/Layout/Accessibility skills;
- check current official shadcn docs;
- follow ElectroCraft Design System/AppShell/Screen specs.

After editing multiple TSX components:
invoke React best-practices skill and apply relevant performance/a11y review.

# AI
Before AI SDK work:
invoke AI SDK skill.
Before AI Workbench message/tool/plan UI:
invoke AI Elements skill.
Install only AI Elements actually used.

# Framework/engine
Use current official primary documentation before pinning/updating:
Puck, Rete, PGlite, Refine, Expo, Capacitor, Slim, WordPress.

# Rule
Skills guide implementation.
They do not override canonical product ownership unless the spec is explicitly updated by ADR/review.
